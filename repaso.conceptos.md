1. Terminal y Git
Acabas de crear un archivo nuevo llamado contacto.html. ¿Cuál es el comando correcto para preparar este archivo antes de guardar el historial (commit)?

[ ] a) git init

[ ] b) git status

[ ] c) git push

[x] d) git add .

Justificación: git add mueve los cambios al área de preparación (staging area). El punto (.) incluye todos los archivos nuevos o modificados en el directorio actual.

2. Estructura HTML
Quieres crear una lista numerada para mostrar los pasos de una receta. ¿Qué etiqueta principal debes utilizar?

[ ] a) <ul>

[x] b) <ol>

[ ] c) <li>

[ ] d) <nav>

Justificación: <ol> significa Ordered List (lista ordenada), que es la que genera números (1, 2, 3...). <ul> es para viñetas y <li> es el elemento individual dentro de la lista.

3. CSS y Flexbox
Tienes un contenedor con display: flex; y notas que los elementos se ponen uno al lado del otro (en fila). ¿Qué propiedad usas para que se apilen uno debajo del otro (en columna)?

[ ] a) justify-content: center;

[ ] b) flex-wrap: wrap;

[x] c) flex-direction: column;

[ ] d) align-items: end;

Justificación: Por defecto, el eje principal de Flexbox es horizontal (row). Al cambiarlo a column, los elementos se alinean verticalmente.

4. JavaScript
Cuando un usuario envía un formulario, la página tiende a recargarse por defecto. ¿Qué instrucción de JS utilizamos dentro del evento para evitar que esto suceda?

[ ] a) console.log("enviado");

[x] b) event.preventDefault();

[ ] c) document.querySelector('form');

[ ] d) window.onload = function();

Justificación: Este método "previene la acción por defecto" del navegador, permitiendo que tu código JavaScript maneje los datos sin que la pantalla se refresque.

5. Archivos Multimedia
Según nuestra investigación de formatos, ¿cuál de las siguientes extensiones de imagen es la más moderna, recomendada para la web por su alta compresión y calidad?

[x] a) .webp

[ ] b) .png

[ ] c) .bmp

[ ] d) .gif

Justificación: WebP ofrece archivos mucho más pequeños que PNG o JPEG manteniendo una excelente calidad, lo que acelera la carga de tu sitio web.
