# Mis Aprendizajes en Desarrollo Web

En este proyecto de práctica he aplicado los siguientes conceptos:

### 1. Formularios en HTML
* **¿Para qué sirve?**: Permite capturar datos del usuario (nombre, email, mensaje).
* **Concepto clave**: Aprendí a usar etiquetas `<label>` vinculadas con el `id` de los `<input>` para mejorar la accesibilidad.

### 2. Estructura Semántica
* **¿Para qué sirve?**: Utilizo etiquetas como `<section>`, `<footer>` y `<h2>` para que el navegador y los buscadores entiendan qué parte de la página es cada cosa.

### 3. CSS Grid (visto en tu código como `grid-proyectos`)
* **¿Para qué sirve?**: Sirve para crear diseños de cuadrícula de forma mucho más fácil y ordenada que los métodos antiguos.

### 4. Atributos de Accesibilidad (Aria-label)
* **¿Para qué sirve?**: Veo que usé `aria-label` para que las personas que usan lectores de pantalla puedan navegar mejor mi formulario.

## 📚 Conceptos Aprendidos

### 1. Estructura HTML5
Aprendí a utilizar etiquetas para crear sitios web accesibles y bien organizados:
* **Semántica:** Uso de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
* **Contenido:** Jerarquía de títulos (`<h1>` - `<h6>`), párrafos (`<p>`), enlaces (`<a>`) e imágenes (`<img>`).
* **Listas:** Organización de información mediante listas ordenadas (`<ol>`) y desordenadas (`<ul>`).
* **Datos y Formularios:** Tablas de datos y formularios de contacto con validaciones básicas.
* **Multimedia:** Integración de elementos externos como videos y mapas mediante `<iframe>`.

### 2. Estilos con CSS3
* **CSS Externo:** Vinculación de hojas de estilo independientes para un código escalable.
* **Estética:** Control de tipografías, paletas de colores y bordes.
* **Modelo de Caja (Box Model):** Comprensión de cómo funcionan los márgenes, rellenos (padding) y bordes en el diseño.

### 3. Control de Versiones con Git
Dominio del flujo de trabajo básico desde la terminal:
1. `git status`: Para verificar el estado de los archivos.
2. `git add .`: Para preparar los cambios (staging).
3. `git commit -m "mensaje"`: Para registrar la versión localmente.
4. `git push`: Para sincronizar los cambios con el repositorio en la nube.
